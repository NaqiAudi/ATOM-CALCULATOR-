# 🪙 ATOM Cash Counter (MYR)

Aplikasi pengiraan wang tunai (cash counter) ringkas, pantas, dan mesra pengguna yang direka khas untuk mata wang Ringgit Malaysia (MYR). Diberdayakan sebagai **Progressive Web App (PWA)**, aplikasi ini boleh dipasang terus pada peranti **iPad (iOS)** dan **Android** tanpa sebarang pemasangan melalui App Store atau Play Store.

---

## 🌟 Ciri-Ciri Utama

* **Sokongan Denominasi MYR Penuh:** Merangkumi wang kertas (RM 100, RM 50, RM 20, RM 10, RM 5, RM 1) dan syiling (RM 0.50, RM 0.20, RM 0.10, RM 0.05) lengkap dengan paparan visual.
* **Kiraan Automatik & Real-Time:** Jumlah sub-nilai dan jumlah keseluruhan dikemaskini secara serta-merta semasa input dimasukkan.
* **Fungsi Kongsi (Share):** Salin atau hantar ringkasan penyata kiraan wang terus ke aplikasi WhatsApp / peranti lain dengan satu klik.
* **Ciri Reset Pantas (Clear):** Membolehkan anda mengosongkan semua ruang input dengan mudah untuk kiraan seterusnya.
* **Mesra Peranti Mobil & Tablet:** Antaramuka yang responsif, sesuai digunakan pada skrin iPad, tablet, dan telefon pintar.

---

## 🚀 Cara Pemasangan Pada Peranti (Add to Home Screen)

Aplikasi ini boleh terus dijadikan seperti aplikasi sistem asal (*native app*) pada peranti anda:

### 🍏 iPad / iPhone (Safari)
1. Buka pautan aplikasi menggunakan pelayar **Safari**.
2. Tekan ikon **Share** (petak dengan anak panah ke atas).
3. Pilih **Add to Home Screen** (Tambah ke Skrin Utama).

### 🤖 Android (Google Chrome)
1. Buka pautan aplikasi menggunakan pelayar **Google Chrome**.
2. Tekan ikon **3 titik** di penjuru atas kanan.
3. Pilih **Add to Home Screen** / **Install app**.

## 🛠️ Teknologi Yang Digunakan

* **HTML5:** Struktur asas halaman dan borang input.
* **CSS3:** Rekabentuk antaramuka (*UI/UX*) dan susun atur responsif.
* **JavaScript (Vanilla JS):** Logik pengiraan matematik, kemaskini tarikh/masa, dan fungsi pautan perkongsian (*Web Share API*).
* **GitHub Pages:** Perkhidmatan *hosting* percuma untuk aplikasi.
